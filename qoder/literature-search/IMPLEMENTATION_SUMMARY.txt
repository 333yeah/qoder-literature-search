核心功能实现
------------
1. 三类检索模式：
   - vector（语义）：cosine_distance + IVF_FLAT 索引
   - fulltext（关键词）：MATCH AGAINST + IK 分词
   - hybrid（混合）：RRF 融合两路结果，score = Σ 1/(k + rank + 1)

2. 标量过滤：
   - topic / source 可选过滤，三路查询均支持

3. HTTP 接口：
   - GET  /api/health          健康检查
   - GET  /api/stats           统计
   - GET  /api/documents       列表
   - POST /api/search          检索
   - POST /api/documents       新增
   - POST /api/seed            导入示例语料
   - DELETE /api/documents/{id} 删除

4. 向量字面量处理：
   - 按 seekdb-notes.md 第 4 节，使用 struct.pack 转 hex，直接拼入 SQL

5. 前端特性：
   - 模式切换（混合/语义/关键词）
   - 过滤下拉（source、topic）
   - 结果卡片（标题、标签、原文、排名徽标、得分）
   - 关键词高亮
   - 统计面板
   - 新增资料表单
   - 文档列表（可删除）
